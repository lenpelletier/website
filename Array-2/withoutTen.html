withoutTen: remove the 10s

Return a version of the array with all the 10's removed. The remaining elements shift left toward the start, and the empty spaces at the end become 0. So {1, 10, 10, 2} gives {1, 2, 0, 0}. Step through withoutTen: i reads every box of nums, but j only moves when something is actually copied, so the kept values pack together on the left.
