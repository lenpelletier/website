fizzBuzz: Fizz, Buzz, FizzBuzz

Consider the numbers from start up to but not including end. Return a new String array with the string form of each number, except use "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for multiples of both. Step through fizzBuzz: here i runs through the actual numbers, so i-start converts each number into its box index. The "both" test has to come first.
