fizzArray3: start up to end

Given start and end numbers, return a new array containing the integers from start up to but not including end, so start = 5 and end = 10 gives {5, 6, 7, 8, 9}. end will be greater than or equal to start. Step through fizzArray3: end-start is exactly how many numbers there are, and start++ hands out one number per box.
