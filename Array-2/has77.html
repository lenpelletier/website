has77: two 7s close together?

Given an array of ints, return true if it contains two 7's next to each other, or two 7's with one element between them, such as {7, 1, 7}. Step through has77: the loop looks three boxes at a time from each 7. It stops early so i+2 stays inside the array, so the last pair is checked separately after the loop. i is declared before the loop so it can still be used afterwards.
