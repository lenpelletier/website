sum13: add up, but 13 is unlucky

Return the sum of the numbers in the array, returning 0 for an empty array. Except the number 13 is very unlucky, so it doesn't count, and the number right after a 13 doesn't count either. Step through sum13: a number is added only if it isn't 13 and the number before it isn't 13. Checking i == 0 first keeps nums[i-1] from looking before the start of the array.
