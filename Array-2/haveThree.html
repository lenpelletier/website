haveThree: exactly three 3s, none touching

Given an array of ints, return true if the value 3 appears exactly 3 times and no 3's are next to each other. Step through haveThree: two 3s side by side mean the answer is false right away; otherwise each 3 gets counted. The loop stops one box early (so i+1 stays in the array), and the last box is checked on its own afterwards.
